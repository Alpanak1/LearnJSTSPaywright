# Learn JavaScript

A collection of JavaScript practice files organized by topic and numbered in learning order. The examples cover fundamentals through loops, including operators, conditions, switch statements, and user input.

## Requirements

- [Node.js](https://nodejs.org/)
- npm

Install the project's dependencies from the repository root:

```sh
npm install
```

## Run an example

Run an individual lesson file with Node.js. For example:

```sh
node 01_chapter_JS_Basics/Helloworld.js
```

Some examples read from the terminal or use `prompt-sync`; run those in an interactive terminal. The chapters are standalone exercises, so choose a file to run rather than starting a single application entry point.

## Topics

1. JavaScript basics
2. Keywords and identifiers
3. Literals
4. Operators
5. Increment and decrement operators
6. Conditional statements
7. Switch statements
8. User input
9. `for` loops
10. `while` loops
11. `do...while` loops
